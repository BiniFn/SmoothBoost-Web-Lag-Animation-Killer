Updating from an older version resets the old Custom feature defaults once. You can turn individual options back on in Custom.

Install and use instructions
  1. Download the SmoothBoost 1.0.6 ZIP and extract it.
  2. Open chrome://extensions in Chrome or Helium and turn on Developer mode.
  3. Choose Load unpacked and select the extracted folder containing manifest.json.
  4. Reload open tabs after installing or updating so the page scripts can start.
  5. Use the Controls tab to choose a profile or switch to Custom to adjust individual controls. The top switch turns SmoothBoost off for this site.
Shortcut: ⌥ Option + Shift + S
